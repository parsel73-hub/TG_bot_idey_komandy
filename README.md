# 🤖 Telegram-бот «Идеи Команды»

Бот для командной работы: добавляет задачи в общий список и умеет выгружать их файлом в формате CSV.

Стек: **Python 3.12**, **aiogram 3.x**, **SQLite3** (через `aiosqlite`)

---

## 📋 Возможности

| Команда       | Описание                                                          |
|---------------|-------------------------------------------------------------------|
| `/start`      | Приветствие + клавиатура с кнопками-командами                        |
| `/add`        | Добавить задачу (бот попросит ввести текст)         |
| `/list`       | Показать все задачи из общего списка                          |
| `/list_csv`   | Отправить задачи файлом в формате CSV                          |

### Что хранится о задаче

Таблица `tasks` в SQLite:

| Поле         | Тип     | Описание                                       |
|---------------|---------|------------------------------------------------|
| `id`          | INTEGER | Уникальный номер задачи                                  |
| `text`        | TEXT    | Текст задачи                                    |
| `user`        | TEXT    | Имя пользователя, добавившего задачу                  |
| `created_at`  | TEXT    | Дата и время добавления                           |

## 📁 Структура проекта

```
ТГбот_ИдеиКоманды/
├── main.py                  # Точка входа (запуск бота)
├── config.py                # Конфиг: токен бота, путь к БД
├── requirements.txt         # Зависимости проекта
├── README.md                  # Этот файл
├── .venv/                    # Виртуальное окружение (создаётся при установке)
├── tasks.db                  # База данных SQLite (создаётся автоматически)
├── database/
│   ├── __init__.py
│   └── db.py               # Работа с базой (aiosqlite)
├── handlers/                # Обработчики команд (роутеры)
│   ├── __init__.py
│   ├── start.py             # Обработчик /start
│   ├── add.py               # Обработчик /add + FSM для ввода текста
│   ├── list_tasks.py        # Обработчик /list
│   └── csv_export.py        # Обработчик /list_csv
└── keyboards/
    ├── __init__.py
    └── reply_kb.py          # Клавиатура с кнопками-командами
```

### Назначение модулей

- **`main.py`** — собирает всё вместе: создаёт бота и диспетчер, подключает роутеры, запускает поллинг обновлений (`long polling`).
- **`config.py`** — единственное место, где хранятся токен и путь к файлу базы данных.
- **`database/db.py`** — все запросы к SQLite: создание таблицы, добавление задачи, получение всех задач.
- **`handlers/*.py`** — логика команд. Каждая команда живёт в своём файле:
  - `add.py` использует **FSM** (конечный автомат): бот «помнит», что ждёт текст задачи от пользователя.
  - `csv_export.py` формирует CSV-файл в памяти (`io.StringIO`) и отправляет его как документ.
- **`keyboards/reply_kb.py`** — reply-клавиатура: кнопки `/add`, `/list`, `/list_csv` под полем ввода.

## 🚀 Установка и запуск

### 1. Склонировать проект (если ещё не на месте)

```powershell
git clone <адрес репозитория>
cd ТГбот_ИдеиКоманды
```

### 2. Создать виртуальное окружение

```powershell
python -m venv .venv
```

### 3. Активировать окружение

Windows:

```powershell
.venv\Scripts\activate
```

Linux / macOS:

```bash
source .venv/bin/activate
```

### 4. Установить зависимости

```powershell
pip install -r requirements.txt
```

### 5. Указать токен бота

Откройте `config.py` и укажите токен от [@BotFather](https://t.me/botfather):

```python
BOT_TOKEN = "1234567890:AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA"
```

> ⚠️ **Для реальных проектов** не храните токен в коде. Используйте переменные окружения или файл `.env` (библиотека `python-dotenv`).

### 6. Запустить бота

```powershell
python main.py
```

При первом запуске автоматически создастся файл базы данных `tasks.db` с таблицей `tasks`.

## 📄 Примечание про CSV

- Файл формируется в памяти, ничего не сохраняется на диск.
- Начинается с **BOM-метки** (`\ufeff`), значения разделяются точкой с запятой (`;`), чтобы **Excel корректно открывал кириллицу**.
- Если база пуста — бот сообщит, что выгружать нечего.

## 🧗 Что можно улучшить (идеи для обучения)

1. Вынести токен в переменную окружения (`.env`).
2. Добавить удаление задачи (`/done <id>` или inline-кнопки).

5. Привязать задачи к конкретному чату (`chat_id` в таблице).
